# Knowledge base guides (drafts)

Guide articles for the M11 knowledge base in the Knowledge view. They are
bundled with the app and indexed for DRIFT when M11 lands. Keep them free of
real hosts, addresses and secrets: use placeholders (`<ct-ip>`, `example.com`,
`192.168.1.0/24`). Links like `[Docker](view:docker)` open a view; keep the
UI names in sync with the app.
