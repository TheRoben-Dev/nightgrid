# Roadmap

What's planned after the shipped milestones (see `CHANGELOG.md` for what's done). The order can change; the knowledge base (M11) stays last so it covers everything before it. External notification channels (ntfy, Discord, email) are left out until decided, since they need an outside service.

| Batch | Scope |
| --- | --- |
| ~~**M10k** · Keys & power~~ | Done: power states, sleep windows and Wake-on-LAN (0.10.12), SSH key manager (0.10.14), group and scheduled power (0.10.15). |
| ~~**M10l** · Watch & history~~ | Done: incident timeline (0.10.16), expiry watch and config drift (0.10.17). |
| ~~**M10m** · Fleet health~~ | Done: update center (0.10.18), disk health and forecast (0.10.19), backup monitor with test restores (0.10.20). |
| ~~**M10n** · VM desktops~~ | Done (0.10.21): built-in VNC viewer over the host's SSH connection (libvirt VNC, Proxmox `qm vncproxy`) and RDP through an SSH tunnel with the system client. |
| ~~**M10o** · Layout customization~~ | Done (0.10.22): Overview dashboards with edit mode (drag, resize, add, remove, undo, reset), several named dashboards, built-in and saved presets, all in profile exports. |
| ~~**M10p** · DRIFT skills~~ | Done: exact checks for commands, compose files, errors and cron (0.10.23); send a command to a terminal, alert triage, daily summary, runbook notes, regex helper and deeper history search (0.10.24). Original scope: Short, grounded tasks a small local model does well: explain a command before running it (flags risky ones like `rm -rf`, `chmod 777`, `--force`); plain words → a command draft you review and send to a terminal (never run by itself); compose/config review (missing restart policies, `:latest`, ports on 0.0.0.0, inline secrets); a daily summary from Nightgrid's own data (restarts, disk, pending updates, alerts); alert triage (likely cause + next step, linked to the view); terminal output or history → a draft runbook note; cron/regex/jq helper both ways; offline error lookup (exit codes, systemd states, common Docker errors) from a bundled reference that M11 extends; DRIFT searches deeper into a host's shell history for the entries relevant to the question (the recent 60 already arrive with host facts since 0.10.11). |
| ~~**M10q** · DRIFT as a guide~~ | Done (0.10.25): seven guided tours that spotlight a control and wait for the user, "What can I do here?", DRIFT offers tours in replies, first-run offer and replay from Settings. Original scope: Multi-step walkthroughs across views (spotlight, wait for the user's action, next step; never clicks); "what can I do here?"; replayable first-run tours. |
| **M10r** · Proxmox suite (when a Proxmox host is in use) | Full Proxmox VE management in the app, so its web UI isn't needed: create, clone and template VMs and containers; ISOs and storage; snapshots and backups (vzdump, Proxmox Backup Server); hardware edits (CPU, memory, disks, NICs, PCI/USB passthrough); bridges and networking; node and cluster status; task log; firewall. Builds on M10h and M10n. Scheduled once a Proxmox host is in use. |
| ~~**M10s** · Smarter alerts~~ | Done: dependency graph and alert folding (0.10.26), runbook notes on alerts (0.10.27), UPS watch through NUT with a cancellable group shutdown (0.10.28). |
| ~~**M10t** · Long-term history~~ | Done: daily uptime bars and outages (0.10.29), a year of hourly metrics with zoomable charts and monthly uptime reports with HTML export (0.10.30). |
| ~~**M10u** · Logs & access~~ | Done: cross-host log search with saved searches and LOG MATCH alerts (0.10.31), login & access audit with logins, failures, bans, users, sudo, keys and findings (0.10.32). |
| **M10v** · Host config editors | Editing what Nightgrid only shows today, each with a diff before applying and typed confirmation where it can lock you out. **Cron/timer editor** (create, edit, enable, disable). **Firewall manager** (ufw, firewalld, nftables) with an auto-rollback timer unless you confirm the connection still works. **Reverse proxy editor** for Caddy and Traefik routes (from M10g's read-only view). **DNS dashboard** for Pi-hole and AdGuard Home: stats, blocklists, local DNS records. |
| **M10w** · Deploy & secrets | **Secrets vault for `.env`**: values stored encrypted (keychain-held key, rule 1), masked in the UI, written to hosts only on deploy, included in encrypted profiles. **Stacks from git**: compose stacks tracked in a git repo you choose; pull, see the diff, deploy, with the M10f snapshot before every change. |
| **M10x** · More signals | **GPU monitoring** (NVIDIA via `nvidia-smi`, AMD via sysfs): load, VRAM, temperature and power on tiles and charts. **Network performance**: `iperf3` between your hosts and latency/throughput history to spot a bad cable or switch port (only between your own hosts, rule 7). **Custom widgets**: any command's output as a dashboard tile with a parse rule and threshold colours (uses M10o layouts). |
| **M11** · Knowledge base | Offline articles and quest-log-style guides with their own images, cross-linked with back/forward; indexed by DRIFT; decode effect on open. |

## Later: after the standalone app is finished

Not scheduled. Nothing here gets built until the app is more or less complete as a standalone product (after M11 and the Proxmox suite).

| Idea | Scope |
| --- | --- |
| **Nightgrid node** · optional companion service | Opt-in, single static Rust binary deployed to a host over SSH; opens no ports and talks to the app only through the SSH tunnel or the tailnet. Read-only by default with per-host allowed actions; one-click uninstall; updates pushed by the app. What it adds: metric history and alerts while the app is closed; scheduled jobs that run with this computer off; a Wake-on-LAN relay for other LAN devices; event streaming instead of polling; server-side log anomaly detection and daily-summary prep for DRIFT; hosting the phone status page. |
